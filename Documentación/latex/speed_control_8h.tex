\doxysubsection{Detailed Description}
Controlador diferencial de velocidad. 

\begin{DoxyAuthor}{Author}
Robinson Correa Morales (\href{mailto:robinson.corream@udea.edu.co}{\texttt{robinson.\+corream@udea.\+edu.\+co}}) 
\end{DoxyAuthor}
Objetivo:\+

Garantizar que ambas orugas giren a la misma velocidad real garantizando movimiento en linea recta, compensando las diferencias físicas entre motores con un control proporcional (P) de lazo cerrado sobre ticks de encoder.

Relación con los módulos de bajo nivel:\+

Lee :\+ encoder\+\_\+get\+\_\+left(), encoder\+\_\+get\+\_\+right() \+[encoder.\+h]\+ Escribe :\+ motors\+\_\+set() \+[Driver\+\_\+\+TB6612\+FNG.\+h]\+ Llamado por :\+ \doxylink{odometry_8h_ad57d4389ef608b9558767dade4e6a608}{odometry\+\_\+update()} o el main, a 100 Hz

Filosofía de diseño:\+

La referencia de velocidad se expresa en mm/\+s y se convierte internamente a ticks/\+ciclo usando mm\+\_\+per\+\_\+tick. Esto desacopla la capa de navegación de los parámetros físicos del encoder.

El PWM resultante se calcula así en cada ciclo:\+

ticks\+\_\+objetivo = (v\+\_\+ref\+\_\+mm\+\_\+s \texorpdfstring{$\ast$}{*} ODO\+\_\+\+DT) /\+ mm\+\_\+per\+\_\+tick

error\+\_\+L = ticks\+\_\+objetivo\+\_\+L -\/ delta\+\_\+ticks\+\_\+L error\+\_\+R = ticks\+\_\+objetivo\+\_\+R -\/ delta\+\_\+ticks\+\_\+R

integral\+\_\+L += error\+\_\+L (si \texorpdfstring{$\vert$}{|}error\+\_\+\+L\texorpdfstring{$\vert$}{|} \texorpdfstring{$>$}{>} DEADBAND) integral\+\_\+R += error\+\_\+R (si \texorpdfstring{$\vert$}{|}error\+\_\+\+R\texorpdfstring{$\vert$}{|} \texorpdfstring{$>$}{>} DEADBAND)

pwm\+\_\+L = FF\+\_\+\+SLOPE\+\_\+\+LEFT \texorpdfstring{$\ast$}{*} \texorpdfstring{$\vert$}{|}target\+\_\+\+L\texorpdfstring{$\vert$}{|} + Kp\texorpdfstring{$\ast$}{*}error\+\_\+L + Ki\texorpdfstring{$\ast$}{*}integral\+\_\+L pwm\+\_\+R = FF\+\_\+\+SLOPE\+\_\+\+RIGHT \texorpdfstring{$\ast$}{*} \texorpdfstring{$\vert$}{|}target\+\_\+\+R\texorpdfstring{$\vert$}{|} + Kp\texorpdfstring{$\ast$}{*}error\+\_\+R + Ki\texorpdfstring{$\ast$}{*}integral\+\_\+R

El feed-\/forward por canal (FF\+\_\+\+SLOPE\+\_\+\+LEFT /\+ FF\+\_\+\+SLOPE\+\_\+\+RIGHT) absorbe la diferencia DC estática entre motores. El PI elimina la varianza corrida a corrida.
