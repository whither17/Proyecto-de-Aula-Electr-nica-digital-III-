void motors\+\_\+set (\begin{DoxyParamCaption}\item[{int}]{left\+\_\+speed}{, }\item[{int}]{right\+\_\+speed}{}\end{DoxyParamCaption})}



Actualiza la consigna de velocidad de ambos motores. 

Aplica una zona muerta independiente para cada motor. Si la magnitud de la velocidad solicitada es inferior al umbral mínimo calibrado, el motor se detiene.

Para velocidades válidas, configura la dirección de giro y calcula el duty cycle PWM correspondiente. Los nuevos valores se aplican posteriormente desde la ISR de PWM para mantener la actualización sincronizada con el período PWM.
