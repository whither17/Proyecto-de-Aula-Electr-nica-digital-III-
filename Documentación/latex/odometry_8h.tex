\doxysubsection{Detailed Description}
Módulo de Odometría. 

\begin{DoxyAuthor}{Author}
Andrés Felipe Agudelo Zapata (\href{mailto:andresf.agudeloz@udea.edu.co}{\texttt{andresf.\+agudeloz@udea.\+edu.\+co}}) 
\end{DoxyAuthor}
Estima la pose del robot (x, y, θ) combinando encoders de cuadratura con el giroscopio del MPU6050 mediante un filtro complementario.

Depende de:\+ encoder.\+h — encoder\+\_\+get\+\_\+left(), encoder\+\_\+get\+\_\+right() imu.\+h — imu\+\_\+data\+\_\+ready(), imu\+\_\+read(), imu\+\_\+get\+\_\+data()
