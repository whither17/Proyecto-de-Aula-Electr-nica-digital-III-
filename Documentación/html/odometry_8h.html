Detailed Description

Módulo de Odometría.

Author
Andrés Felipe Agudelo Zapata (andre.nosp@m.sf.a.nosp@m.gudel.nosp@m.oz@u.nosp@m.dea.e.nosp@m.du.c.nosp@m.o)

Estima la pose del robot (x, y, θ) combinando encoders de cuadratura con el giroscopio del MPU6050 mediante un filtro complementario.

Depende de: encoder.h — encoder_get_left(), encoder_get_right() imu.h — imu_data_ready(), imu_read(), imu_get_data()

Unidades del sistema: Posición → milímetros (mm) Ángulo → radianes, rango normalizado (-π, π] Tiempo → segundos (internamente)

◆ odometry_init()

bool odometry_init ( const odo_params_t * params,
const pose_t * init_pose )

Inicializa el módulo con los parámetros físicos del robot y realiza la calibración del bias del giroscopio.

IMPORTANTE: el robot debe estar quieto y nivelado durante toda la calibración (ODO_CALIB_SAMPLES * ODO_DT segundos ≈ 2 segundos).

Parameters
paramsParámetros físicos del robot odo_params_t
init_posePose inicial del robot
Returns
true Inicialización y calibración exitosas
false La IMU no respondió o no se pudo completar la calibración
