uint32_t motor_get_ticks ( void )

Obtiene el número de períodos PWM transcurridos. Devuelve el contador de eventos de wrap acumulados por la ISR del PWM desde la inicialización del controlador.

La lectura se realiza de forma atómica deshabilitando temporalmente la interrupción PWM.

Returns
Número de eventos PWM wrap acumulados.

◆ motors_set()

void motors_set ( int left_speed,
int right_speed )

Actualiza la consigna de velocidad de ambos motores.

Aplica una zona muerta independiente para cada motor. Si la magnitud de la velocidad solicitada es inferior al umbral mínimo calibrado, el motor se detiene.

Para velocidades válidas, configura la dirección de giro y calcula el duty cycle PWM correspondiente. Los nuevos valores se aplican posteriormente desde la ISR de PWM para mantener la actualización sincronizada con el período PWM.

Parameters
left_speedConsigna del motor izquierdo.
right_speedConsigna del motor derecho.
